= MetroCluster FC 구성에서 Brocade FC 스위치 RCF 파일 다운로드
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
MetroCluster 패브릭 구성의 각 스위치에 참조 구성 파일(RCF)을 다운로드해야 합니다.

.이 작업에 대해
이러한 RCF를 사용하려면 시스템에 ONTAP 9.1 이상 버전이 설치되어 있어야 하며, ONTAP 9.1 이상 버전의 포트 레이아웃을 사용해야 합니다.

FibreBridge 브리지에서 FC 포트 중 하나만 사용하려는 경우 섹션에 있는 지침을 사용하여 백엔드 파이버 채널 스위치를 수동으로 구성하십시오. link:concept_port_assignments_for_fc_switches_when_using_ontap_9_1_and_later.html["FC 스위치에 대한 포트 할당"] .

.단계
. Brocade RCF 다운로드 페이지의 RCF 표를 참조하여 구성의 각 스위치에 맞는 올바른 RCF를 확인하십시오.
+
RCF는 올바른 스위치에 적용해야 합니다.

. 해당  https://mysupport.netapp.com/site/products/all/details/metrocluster-rcf/downloads-tab["MetroCluster RCF 다운로드"] 페이지에서 스위치용 RCF 파일을 다운로드하십시오.
+
파일은 스위치로 전송할 수 있는 위치에 배치해야 합니다. 2스위치 패브릭을 구성하는 4개의 스위치마다 별도의 파일이 있습니다.

. 구성의 각 스위치에 대해 이 단계를 반복합니다.
