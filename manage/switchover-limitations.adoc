= MetroCluster 구성이 스위치오버 상태일 때 제한 사항이 있습니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
시스템이 전환되는 동안 NetApp에서는 특정 작업을 수행하지 않도록 권장합니다.

시스템이 전환 중일 때는 다음과 같은 작업을 권장하지 않으며, NetApp 지원팀의 안내에 따라서만 수행해야 합니다.

* 애그리게이트 생성 또는 삭제
* 볼륨 생성 또는 삭제(암호화된 볼륨 포함)
* SVM 생성 또는 삭제
* LIF 생성 또는 삭제
* 디스크 추가 또는 제거(복구 절차의 일부로 디스크를 교체하는 경우에만 해당)
* SnapMirror SVM DR에 대한 구성 변경 수행
* 기존 브로드캐스트 도메인을 수정하거나 새 브로드캐스트 도메인을 만듭니다
* 네트워크 서브넷을 수정합니다




[[hardware-replacement-in-switchover]]
== 전환 시 하드웨어 교체

시스템이 스위치오버 중일 때 컨트롤러 하드웨어를 교체하려면 다음 절차를 따르십시오.

* 스위치오버가 아닌 사이트에서 동일한 유형의 컨트롤러를 교체해야 하는 경우 ~ 절차를 따릅니다link:../disaster-recovery/task_recover_from_a_multi_controller_and_or_storage_failure.html["멀티 컨트롤러 또는 스토리지 장애로부터 복구합니다"].
+
** 정상 사이트에서 노드 스위치를 전환하는 동안 컨트롤러 모듈과 섀시를 교체해야 하는 경우 두 컨트롤러를 모두 종료하고 에 절차를 link:../disaster-recovery/task_recover_from_a_multi_controller_and_or_storage_failure.html["멀티 컨트롤러 또는 스토리지 장애로부터 복구합니다"]수행하십시오.


* 컨트롤러를 다른 유형의 컨트롤러로 교체해야 하는 경우 의 구성 절차를 link:../upgrade/concept_choosing_controller_upgrade_mcc.html["컨트롤러 업그레이드 절차를 선택합니다"]따르십시오.
+
** 컨트롤러 장애로 인해 시스템이 전환 중이거나 스위치오버 중에 컨트롤러 장애가 발생한 경우 먼저 컨트롤러 하드웨어를 교체하고 스위치백을 수행한 다음 컨트롤러 업그레이드를 수행해야 합니다.
+
... 컨트롤러 하드웨어를 교체하고 스위치백을 수행하려면 을 참조하십시오link:../disaster-recovery/task_recover_from_a_multi_controller_and_or_storage_failure.html["멀티 컨트롤러 또는 스토리지 장애로부터 복구합니다"].
... 하드웨어를 교체한 후 의 절차에 따라 컨트롤러 업그레이드를 link:../upgrade/concept_choosing_controller_upgrade_mcc.html["컨트롤러 업그레이드 절차를 선택합니다"]수행합니다.

== 스위치오버 시 SVM 스토리지 제한 변경

ONTAP 9.20.1부터 MetroCluster IP 구성의 일부인 SVM에 대해 스토리지 제한을 구성할 수 있습니다.


CAUTION: MetroCluster 구성이  https://hwu.netapp.com/["Hardware Universe"^]에 나열된 플랫폼 제한을 초과하지 않도록 해야 합니다.

* 정상 작동 중(전환 중이 아닌 경우)에는 *동기화 소스 SVM*에서만 스토리지 제한 구성을 변경할 수 있습니다. *동기화 대상 SVM*에서는 스토리지 제한을 활성화, 비활성화 또는 수정할 수 없습니다.
* 전환 과정 중에는 *동기화 대상 SVM*에 다음과 같은 제한 사항이 적용됩니다:
+
**  `vserver modify -storage-limit` 명령어를 사용하여 동기화 대상 SVM의 스토리지 제한을 활성화 또는 비활성화할 수 없습니다. 즉, 값을 0에서 0이 아닌 값으로 변경하거나 0이 아닌 값에서 0으로 변경할 수 없습니다. 다음 오류가 발생하며 명령이 실패합니다:
+
`This operation is not permitted on a Vserver that is configured as the destination of a MetroCluster Vserver relationship`

** 여전히 스토리지 제한을 0이 아닌 한 값에서 다른 값으로(예: 100TB에서 200TB로) 변경할 수 있습니다. 이 새로운 값은 스위치백 후에도 유지됩니다.
** 저장 용량 제한을 활성화 또는 비활성화하려면 스위치백이 완료될 때까지 기다린 후 *동기화 소스 SVM*에서 변경하십시오. 그러면 해당 값이 동기화 대상 SVM으로 복제됩니다.




자세한 내용은 link:https://docs.netapp.com/us-en/ontap/volumes/manage-svm-capacity.html["ONTAP SVM 용량 관리"^]을(를) 참조하십시오
