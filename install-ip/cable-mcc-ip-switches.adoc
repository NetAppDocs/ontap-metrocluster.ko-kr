= RCFfilegenerator 툴과 Hardware Universe를 사용하여 MetroCluster IP 스위치를 케이블링합니다.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
스위치를 올바르게 케이블링하려면 RCFfilegenerator 툴 사용 방법과 NetApp Hardware Universe의 정보를 이해해야 합니다.

.시작하기 전에
이 작업을 수행하기 전에 link:using_rcf_generator.html["MetroCluster IP 스위치 케이블 연결에 대해 알아보십시오."]에 있는 정보를 검토하십시오.

.단계
. NetApp 지원 사이트에서  https://mysupport.netapp.com/site/tools/tool-eula/rcffilegenerator["MetroCluster IP용 RcfFileGenerator입니다"^] 툴을 다운로드하여 설치하십시오.
. link:https://kb.netapp.com/on-prem/ontap/mc/MC-KBs/How_to_use_the_RCF_Generator_for_MetroCluster_IP["MetroCluster IP용 RCF 생성기 사용 방법"^]의 단계를 따라 구성에 대한 필드를 입력하십시오.
+
이 툴은 각 스위치에 대한 포트별 케이블 연결 개요를 생성합니다.

+

NOTE: RcfFileGenerator는 첫 번째 플랫폼을 선택한 경우에만 적합한 플랫폼을 표시합니다.

. 다음으로 이동하십시오 link:https://hwu.netapp.com/DetailViews/Home.aspx["Hardware Universe"^]
. *제품* 탭에서 플랫폼 유형을 선택한 다음, 특정 플랫폼을 선택하고 4노드 또는 8노드 MetroCluster IP 구성을 케이블링할지 여부를 선택합니다.
. 표시 창에서 ONTAP 버전을 선택한 다음 *결과 보기*를 선택하십시오.
. *지원되는 연결*을 선택하고 *스토리지 연결* 탭을 선택하십시오.
. 구성에 대한 컨트롤러 포트 정보를 수집하십시오.
+

NOTE: 컨트롤러 포트 정보는 RcfFileGenerator 툴에서 생성된 케이블링 개요에 포함되어 있지 않으므로 Hardware Universe를 사용하여 이 정보를 수집해야 합니다.
