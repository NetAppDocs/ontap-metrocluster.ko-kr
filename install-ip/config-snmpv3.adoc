= MetroCluster IP 스위치의 상태를 모니터링하기 위해 SNMPv3 구성
:allow-uri-read: 


[role="lead"]
MetroCluster IP 구성에서 IP 스위치의 상태를 모니터링하도록 SNMPv3을 구성할 수 있습니다.

이 절차에서는 스위치에서 SNMPv3를 구성하는 일반적인 단계를 보여줍니다. 나열된 일부 스위치 펌웨어 버전은 MetroCluster IP 구성에서 지원되지 않을 수 있습니다.

MetroCluster IP 구성에서 지원되는 스위치 펌웨어 버전에 대한 단계를 따라야 합니다 . link:https://hwu.netapp.com["Hardware Universe"^] 지원되는 펌웨어 버전을 확인하세요.

[NOTE]
====
* SNMPv3는 ONTAP 9.12.1 이상에서만 지원됩니다.
* ONTAP 9.13.1P12, 9.14.1P9, 9.15.1P5, 9.16.1 및 이후 버전은 다음 두 가지 문제를 해결합니다.
+
** link:https://kb.netapp.com/on-prem/ontap/OHW/OHW-Issues/CONTAP-82891["Cisco 스위치의 ONTAP 상태 모니터링의 경우 모니터링을 위해 SNMPv3으로 전환한 후에도 SNMPv2 트래픽이 계속 표시될 수 있습니다."^]
** link:https://kb.netapp.com/on-prem/ontap/OHW/OHW-Issues/CONTAP-119131["SNMP 장애 발생 시 거짓 양성 스위치 팬 및 전원 경고"^]




====
.이 작업에 대해
다음 명령은 * Broadcom *, * Cisco * 및 * NVIDIA * 스위치에서 SNMPv3 사용자 이름을 구성하는 데 사용됩니다.

[role="tabbed-block"]
====
.Broadcom 스위치
--
Broadcom BES-53248 스위치에서 SNMPv3 사용자 이름 네트워크 운영자를 구성합니다.


NOTE: ONTAP 9.20.1 버전부터 Broadcom 스위치에서 SHA-512 인증을 구성할 수 있습니다.

* 인증 없음 * 의 경우:
+
[source, cli]
----
snmp-server user <snmpv3-user> NETWORK-OPERATOR noauth
----
* *MD5/SHA/SHA-512 인증*의 경우:
+
[source, cli]
----
snmp-server user <snmpv3-user> NETWORK-OPERATOR [auth-md5|auth-sha|auth-sha512]
----
* *AES/DES 암호화를 사용하는 MD5/SHA/SHA-512 인증*의 경우:
+
[source, cli]
----
snmp-server user <snmpv3-user> NETWORK-OPERATOR [auth-md5|auth-sha|auth-sha512] [priv-aes128|priv-des]
----


다음 명령을 실행하면 ONTAP 측에서 SNMPv3 사용자 이름이 구성됩니다.

[source, cli]
----
security login create -user-or-group-name <snmpv3-user> -application snmp -authentication-method usm -remote-switch-ipaddress <address>
----
다음 명령을 실행하면 CSHM에서 SNMPv3 사용자 이름이 설정됩니다.

[source, cli]
----
cluster1::*> system switch ethernet modify -device <switch-name> -snmp-version SNMPv3 -community-or-username <snmpv3-user>
----
.예시 단계
. SHA 인증 및 AES-128 암호화를 사용하도록 스위치에서 SNMPv3 사용자를 설정합니다:
+
[listing, subs="+quotes"]
----
(sw1)(Config)# *snmp-server user SNMPv3shaAes128 NETWORK-OPERATOR auth-sha priv-aes128*

(sw1)(Config)# *show snmp user snmp SNMPv3shaAes128*

.Cisco 스위치
--
Cisco Nexus 스위치에서 SNMPv3 사용자 이름을 `<snmpv3-user>` 구성합니다.


NOTE: ONTAP 9.20.1 버전부터 Cisco 스위치에서 SHA-512 또는 SHA-256 인증을 구성할 수 있습니다.

* 인증 없음 * 의 경우:
+
[source, cli]
----
snmp-server user <snmpv3-user> NoAuth
----
* *MD5/SHA/SHA-256/SHA-512 인증*의 경우:
+
[source, cli]
----
snmp-server user <snmpv3-user> auth [md5|sha|sha-256|sha-512] <auth-password>
----
* *AES/DES 암호화를 사용하는 MD5/SHA/SHA-256/SHA-512 인증*의 경우:
+
[source, cli]
----
snmp-server user <snmpv3-user> AuthEncrypt auth [md5|sha|sha-256|sha-512] <auth-password> priv [aes-128|des] <priv-password>
----


다음 명령을 실행하면 ONTAP 측에서 SNMPv3 사용자 이름이 구성됩니다.

[source, cli]
----

----
다음 명령을 실행하면 CSHM에서 SNMPv3 사용자 이름이 설정됩니다.

[source, cli]
----
cluster1::*> system switch ethernet modify -device <switch-name> -snmp-version SNMPv3 -community-or-username <snmpv3-user>
----
